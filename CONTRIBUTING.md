# Contributing to the AW-001 Protocol Preview

This is a research protocol preview. External review is welcome through issues
and pull requests.

## Contributor License Agreement

Before a contribution can be merged, the contributor must sign the Inceptless
Contributor License Agreement at
<https://cla-assistant.io/haeliotang/axioweave-protocol>. A PR is merged only
after the CLA check (`license/cla`) passes. See `CLA.md`.

## Scope and evidence

- Keep changes within the AW-001 protocol artifacts.
- State the exact snapshot/tag and commands used.
- Do not add runtime code, credentials, private data, or production material.
- Protocol changes need a new version; do not silently rewrite a signed
  baseline.

By submitting a contribution, you confirm you have the right to license it under
the applicable project license.
