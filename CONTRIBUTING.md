# Contributing

This repository is a published research candidate. External review is welcome
through issues and pull requests.

- Keep changes scoped to the AW-001 protocol artifacts.
- State the snapshot/tag and the exact test command used.
- Do not add Runtime code, credentials, private data, or production material.
- Protocol changes need a separate version and should not silently rewrite a
  signed baseline.

By submitting a contribution, you confirm you have the right to license it under
Apache-2.0.
